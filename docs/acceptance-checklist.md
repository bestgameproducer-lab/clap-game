# 人工验收清单

每项用真实手机完成；涉及秘密身份时由两名测试者互相观察是否会泄露。

## 宾客入口

- [ ] 邀请码错误时看不到宾客名单。
- [ ] 中文、拼音和英文名均可搜索到目标宾客。
- [ ] 首次认领要求设置并确认四位数字密码，错误格式有清晰提示。
- [ ] 已认领宾客必须用原密码登录，其他宾客无法通过姓名进入。
- [ ] 同一宾客在另一台手机上可用姓名和原密码登录。
- [ ] 抽卡只发生一次；刷新和重复点击不会更换组别、身份或首轮任务。
- [ ] 关闭宾客注册后，尚未抽卡的身份不能再分配组别、角色或任务，并显示联系工作人员；已抽卡宾客刷新时仍能安全返回原卡。
- [ ] 关闭注册后，未设置密码的姓名不再出现在名单中且不能首次认领；已经设置密码的宾客仍可用原密码重新登录、投票和查看揭晓。
- [ ] 抽卡页在 320–430px 宽手机上无文字重叠、横向滚动或按钮遮挡。
- [ ] 切到其他应用再回来时，秘密卡自动盖住。

## 任务和奖励

- [ ] 正式任务模式为 `live`，第一幕只会派发 P1-001 至 P1-008；设计中明确删除的旧任务不会再进入抽卡池。
- [ ] 固定剧情职务人数通过预检：誓词 1、戒指 2、双方应援各 1、掌声 1–2、爱心 5，且任何固定职务均不是恶作剧者。
- [ ] 恶作剧者第一幕抽到和普通玩家相同的 P1-007/P1-008，审核成功但个人分不变、不会获得前三额外分或升级任务。
- [ ] 爱心和星星联盟必须由双方互输玩家编号后成立；星星玩家能在任务展开区看见左/右半星、同半边不能配对、成功后播放合并动画；各自最后一位才解锁孤单丘比特/领航星。
- [ ] 切换到第二幕只创建一次 20 张互斥任务/能力卡：张昳睿固定致辞，两队各 1 名恶作剧者和 1 名双重裁决，全场 1 名超级幸运星；重复切换不重复派发。
- [ ] 双重裁决只能选一名目标但按 2 票计，个人投中奖励仍只发 1 次；后台、团队多数和恶作剧逃脱结算使用同一权重。
- [ ] 超级幸运星在第二幕解锁时快照第一阶段积分，揭晓时只发一次同等奖励，不改写原有积分流水。
- [ ] 恶作剧者最多试探三名不同宾客；普通宾客不会从 API、任务页或大屏看到试探对象、暗号结果或同伴关系。
- [ ] 联盟左右成员只收到各自的半条线索，单一响应中不包含另一片段或完整线索。
- [ ] 第一幕公开大屏不显示个人实时积分榜，但团队进度仍可展示。
- [ ] 打印宾客卡页面要求管理员会话，并且不打印基础隐藏阵营。

- [ ] 未到对应阶段的任务不会提前显示。
- [ ] 宾客只可在第一轮、第二轮和团队挑战中提交当前或已经开放的任务；投票/揭晓后手机端隐藏提交与照片入口，直接调用 API 和数据库函数也会被拒绝。
- [ ] 提交后显示待审核；退回后显示原因并允许再次提交。
- [ ] 每项任务显示明确的验证方式；宾客可附带完成说明，提交后后台和任务站均能看到。
- [ ] 宾客可选上传、更换或删除一张验证照片；超过限制的照片会先在手机端压缩，上传失败不会阻止线下核验。
- [ ] 任务站可替宾客添加、更换或删除尚未完成任务的验证照片；待核验照片同样先压缩、只存私有空间，所有工作人员确认或删除均进入审计日志。
- [ ] 验证照片不公开、不进入离线缓存；只有任务本人和已登录工作人员能通过短时链接查看。
- [ ] 后台或任务站点击“通过并加分”不依赖浏览器弹窗；审核备注留空时自动记录任务预设的核验要求，填写时保存现场备注；退回必须填写宾客可见原因。
- [ ] 通过后任务立即离开待审核列表，宾客可查看核验记录，任务 CSV 包含说明、核验人员和核验时间。
- [ ] 通过后只加分一次，重复请求不会重复加分。
- [ ] 任务库和 API 只接受 1–3 点个人积分；普通任务默认 1 分、升级/常规隐藏任务默认 2 分、隐藏间谍任务默认 3 分。
- [ ] 前 10 位首轮通过者各获升级任务，前 3 位另获 1 点个人积分和线索；第 4–10 位不获额外 1 分，第 11 位不再获得升级任务。
- [ ] 私人任务、角色和线索不会出现在公共接口或未揭晓的大屏。
- [ ] 后台可为每项启用的隐藏任务生成一次性实体卡代码；原码只显示一次，后台数据、CSV、审计和公共接口均不返回原码或散列。
- [ ] 任务站只能给已抽卡宾客兑换有效代码；兑换会原子派发对应任务，同一实体卡重复输入、并发输入或换人输入均不会重复派发。
- [ ] 隐藏实体卡只可在第二轮任务或团队挑战环节兑换；其他环节的任务站按钮和数据库操作均关闭。

## 后台与终局

- [ ] 使用 32 位正式宾客时，后台预检能验证家人组 10 人、海岛组和沙漠组各 10 人，以及每个竞技组最多 1 名丘比特恶作剧者、9 名婚礼守护者；任何预设超额都会阻止显示“可以开场”。
- [ ] 后台必须把公开示例邀请码更换为正式码后才能显示“可以开场”；数据库、后台读取接口和审计日志均不返回邀请码原文。
- [ ] 预检会同时检查第一阶段正式任务、固定剧情职务人数、第二阶段配置状态、团队任务、四张带代码的隐藏卡、三条通用线索、每位初始恶作剧者的专属线索、全部主持环节真实答案和两队竞拍钱包。
- [ ] 彩排清场只有在注册、投票和大屏均关闭后才能执行，并同时要求八类备份确认、3–300 字原因、固定确认词和浏览器最终确认。
- [ ] 重复提交同一个清场事件不会重复写入审计；清场保留配置、管理员会话和审计，但删除全部宾客运行数据并释放已兑换隐藏卡。
- [ ] 清场把未锁定的随机队伍/身份恢复为未分组/普通宾客，保留后台锁定的初始预设，并把隐藏间谍恢复为普通宾客。
- [ ] 清场后的验证照片从私有存储删除；若存储临时失败，待删除路径只保存在受保护记录中，并可使用同一事件安全重试。

- [ ] 错误管理员密码无法登录；未登录不能读取后台数据或 CSV。
- [ ] 同一设备连续输错五次管理员密码后收到 429 和明确等待时间，十五分钟内即使继续尝试也不会创建工作人员会话；数据库只保留不可逆指纹。
- [ ] 后台、主持台和任务站均可安全退出；退出后原管理员 Cookie 立即失效，不能继续读取任何工作人员数据。
- [ ] 后台可新增宾客并修改显示姓名、登录名、桌号、长辈标记、仪式任务标记和工作人员备注；导出的宾客 CSV 包含这些运营字段。
- [ ] 关闭注册后可从三列表格或分隔文本批量预览并新增 1–100 位宾客；重复、已存在或格式错误的登录名会让整批回滚，注册开放时前端、API 和数据库均拒绝导入。
- [ ] 已设置密码的宾客不能直接更换登录名；停用未抽卡宾客会立即撤销其全部会话，并从认领名单和任务站消失。
- [ ] 已经抽卡的宾客不能被停用，避免其任务、组别完成率和积分历史失去归属。
- [ ] 重置密码后，宾客现有会话失效且可以重新设置密码。
- [ ] 开启投票会隐藏旧揭晓；公布结果会关闭投票。
- [ ] 每位宾客每轮只能投一次，提交后立即锁定；重新开放会创建新轮次且不会混入旧票。
- [ ] 公布结果时，猜中间谍的宾客自动获得 1 分；多数票猜中的队伍获得 3 分；首轮完成率超过 50%/75%/100% 分别获得 1/2/3 团队分。
- [ ] 公开团队榜只汇总团队积分流水；个人任务分无论多高都不能改变团队排名，但仍正常显示在个人荣誉榜。
- [ ] 旧版 10–40 分任务迁移到 1–3 分尺度时，已通过任务使用负向校准流水同步调整宾客总分，原审核和积分流水不会被删除或重写。
- [ ] 环节下拉框不能直接选择“最终投票”或“身份揭晓”；API 与数据库同样拒绝绕过专用按钮，避免产生没有轮次或没有结算的终局状态。
- [ ] 后台可发布或清空最多 500 字的宾客端环节提示；宾客手机自动同步，公开大屏不显示这条内部行动提示，操作进入审计。
- [ ] 开启新投票只允许从团队挑战或既有终局进入，至少已有一位宾客完成抽卡；系统自动关闭注册、创建新轮次并清空上一题、线索和倒计时。
- [ ] 隐藏揭晓或切回常规环节会明确提示已结算积分不会撤销；终局阶段不能重新开放注册。
- [ ] 重复点击“公布并结算”、隐藏后再次公布或请求重试，不会重复发放任何终局奖励。
- [ ] 因现场纠错而重新开启投票轮次时，已发放的同类个人或团队终局奖励也不会跨轮次重复发放。
- [ ] 恶作剧者保留身份、伪装任务、同伴确认和最终揭晓，但后台、宾客端和公开大屏均不存在独立恶作剧积分或补记入口。
- [ ] 公布结果不会因恶作剧者逃脱投票、所在队伍第一或完成恶作剧任务而额外写入个人、团队或独立积分。
- [ ] 大屏开关独立生效，未开放时不显示排名数据。
- [ ] 结果未公布时，大屏不显示秘密身份或个人投票。
- [ ] 主持人页显示每队初始 10 枚丘比特金币；成交扣减和返还均记录余额、原因和操作人，请求重试不重复记账，且任何队伍都不能透支。
- [ ] 丘比特金币不计入个人或团队积分，也不出现在公开大屏；只在受保护的主持页、审计和专用导出中出现。
- [ ] 七种 CSV（宾客、任务、个人积分、团队积分、竞拍金币、奖项、审计）均能下载并用 Excel 打开，且不包含密码哈希、会话或服务密钥。
- [ ] 后台状态修改、审批、派发、积分调整和密码重置均出现在审计记录中。
- [ ] 后台可新建、编辑和停用任务与线索；停用内容不再出现在派发列表，已领取内容仍可查看。
- [ ] 任务派发后可以修正文案和停用，但不能修改积分、身份范围、类型或开放阶段。
- [ ] 后台可把线索设置为通用或绑定具体间谍，并选择一级、二级或三级；每位预设间谍的专属线索覆盖状态清晰可见。
- [ ] 前三名自动获得的专属线索只指向本队间谍；间谍本人不会自动收到暴露自己的专属线索，没有匹配线索时才使用通用线索。
- [ ] 线索发放后不能更换对应间谍或等级，但可以修正文案或停用；宾客端、任务站和公开大屏均不返回 `spy_guest_id`。
- [ ] `/host` 未登录时看不到题库；登录后可以看到主持词和正确答案。
- [ ] `/host` 显示当前阶段、注册/大屏状态和本轮投票完成数；身份未揭晓前不展开票数排名，揭晓后按票数显示姓名与组别。
- [ ] `/station` 未登录时看不到宾客进度；登录后可按姓名、登录名或组别搜索，但始终看不到秘密身份和密码信息。
- [ ] 任务站直接通过一项任务只记一次分；重复点击不会重复加分。
- [ ] 未选择获奖宾客或组别时不能发布奖项；未公开总结果时公开大屏不显示奖项。
- [ ] 未勾选“允许发布”的环节不能发布；发布后大屏只有公开题目和公开线索，不含主持词或答案。

## 弱网和恢复

- [ ] 登录后断网，页面显示离线提示和最近缓存，不显示白屏。
- [ ] 主持人流程台成功同步一次后，断网仍能查看当前标签页最近的私密台词和答案；发布环节、团队计分和金币调整全部禁用，恢复联网后自动同步，也可手动重连。
- [ ] 主持人私密离线副本只存在于当前标签页的 `sessionStorage`；安全退出或工作人员会话返回 401 后被清除，`localStorage` 和 Service Worker 中均不存在主持答案。
- [ ] 任务站成功同步一次后，断网仍能搜索并查看当前标签页最近的宾客和任务文字；核验、退回、实体卡兑换、派发、发线索和积分补记全部禁用，恢复联网后自动同步，也可手动重连。
- [ ] 任务站私密离线副本只存在于当前标签页的 `sessionStorage`；安全退出或工作人员会话返回 401 后被清除，验证照片与 `/api/` 响应均不进入 Service Worker 缓存。
- [ ] 大屏成功联网一次后，当前投影标签页断网或刷新仍可打开页面壳和最近公开结果；页面显示 `CACHED`、最近同步时间和重连按钮，不会把 API 响应或揭晓结果写入长期 `localStorage`。
- [ ] 联网打开一次宾客任务页并看到“弱网备用已准备”后，切断网络再刷新，页面壳和本次会话最近任务仍可打开。
- [ ] Service Worker 缓存中没有 `/api/` 响应，也无法离线打开 `/admin`、`/host` 或 `/station`。
- [ ] 断网时点击“退出此身份”会明确提示需要联网，不会假装退出；恢复网络后退出会撤销服务器会话并清除本机任务缓存。
- [ ] 恢复网络后页面自动拉取最新阶段和任务。
- [ ] 微信内置浏览器中进入姓名搜索页不会自动弹出键盘；手动输入时页面随键盘可视高度调整，输入框不被遮住，也不会触发 iPhone 页面自动放大。
- [ ] 在带刘海或底部手势条的 iPhone 上，登录、抽卡、身份遮挡、任务、后台、主持台、任务站和大屏的顶部内容及底部按钮均位于安全区内。
- [ ] 现场负责人已读完操作手册，知道纸卡和人工补录流程。
