# 主持人完整婚礼流程指南

访问入口：`/host`

## 这份指南怎么用

这是一份可以放在主持人手机旁、照着按钮逐项执行的现场手册。婚礼当天先看页面顶部的“下一步建议”，再按本指南对应环节操作。每次切换流程或执行终局动作，系统都会要求第二次确认；只有看到绿色成功提示和页面状态更新，才算操作完成。

主持人台包含宾客组别、个人积分和恶作剧者身份，只能在主持人自己的设备上查看。不要投屏、截图发群、把手机交给宾客，或在身份揭晓前念出任何隐藏信息。

## 工作人员分工

1. **主持人**：掌握现场节奏、切换婚礼环节、记录团队与个人现场奖励、发起投票并完成揭晓。
2. **主控负责人**：使用 `/admin` 管理宾客、内容、任务审核、线索、奖项、备份和异常修复。
3. **任务站负责人**：使用 `/station` 审核宾客任务证据、通过或退回任务。
4. **现场协助者**：帮助宾客扫码、找到姓名和理解页面，不接触后台密码或隐藏身份。

主持人不要代替任务站审核照片，也不要在主持台修改宾客身份、重置密码、创建线索或进行彩排清场。

## 主持人现场一分钟速查

1. 页面顶部“下一步建议”是当前最应该做的事情；点击卡片内按钮会带你到对应入口，但不会直接执行危险操作。
2. 查看人员和分数：点“全员总览”。
3. 主持团队游戏、抽题、计时或抽取数字：点“主持游戏”。
4. 团队游戏结束后记海岛组或沙漠组成绩：点“团队计分”。
5. 主持人临时宣布某位宾客获得个人奖励：点“个人加分”。
6. 推进婚礼环节、发线索、开关投票和公布结果：点“流程控制”。
7. 所有写入操作都要等待绿色成功提示。出现红色提示时不要重复点，把完整提示交给主控负责人。
8. 页面显示“离线只读”时不能加分或切换流程；先恢复网络，再点“重新连接”。

## 登录后先认识主持人台

1. 打开 `/host`，输入工作人员密码，点“进入主持人台”。不要把密码保存在公共设备，也不要让宾客代为输入。
2. 登录后先看顶部状态：当前婚礼环节、多少宾客已认领、多少任务待审核，以及页面是否显示在线。
3. 再看“下一步建议”。例如它可能显示“进入等待仪式”“记录团队挑战成绩”或“开启最终投票”。点击建议按钮只会切换到相关操作区，主持人仍需核对并确认。
4. 页面中间有五个固定入口：
   - “全员总览”：核对姓名、组别、抽卡状态、个人积分和恶作剧者身份；这里是私密信息，不可投屏。
   - “主持游戏”：打开四个只读现场助手；题库与答案仅在工作人员登录后加载。
   - “团队计分”：只记录海岛组、沙漠组的现场团队挑战成绩。
   - “个人加分”：只记录主持人明确宣布的临时个人奖励。
   - “流程控制”：切换七个婚礼环节，并执行团队结算、开票、关票和公布结果。
5. 如果进入了错误入口，直接点另一个入口即可；未点击最终确认前，不会更改现场数据。

## 如何使用全员总览

1. 点“全员总览”。
2. 用名单核对宾客姓名、组别以及“已抽卡 / 待抽卡 / 专属卡”状态。
3. 右侧显示个人积分；家人若不参与计分会显示“不计分”，但可获得个人积分的家人会正常显示分数。
4. 已抽卡的恶作剧者会被主持人台私密标识。主持人只能据此掌握流程，身份揭晓前绝不能念出、投屏或把手机递给宾客。
5. 主持人台不能重置宾客密码、修改身份或审核照片；这些问题交给主控或任务站。

## 如何使用主持游戏助手

1. 点“主持游戏”，再选择快问快答、你比划我猜、田忌赛马或一站到底。工具只帮助主持，不会自动切换婚礼环节或修改积分。
2. **快问快答**：先选本轮类别，再选当前答题组。三组必须使用同一类别和同一题序；点“开始”后可以单独显示答案。答错、超时或跳过时点“结束”，不要念出答案；平分时才展开两道备用题。
3. **你比划我猜**：选词库后点“开始 5 分钟”。每个词使用“猜对 · 下一词”或“跳过 · 换词”，本轮不会重复出现已经使用的词；如现场暂停，先点“暂停计时”。
4. **田忌赛马**：按规则选择“奖励数 1–10”或“队员号码 0–9”，也可输入自定义整数范围，再点“随机抽取一个数字”。每次抽取独立，允许重复，结果仅保留在当前页面。
5. **一站到底**：先选择题目，让宾客站到新郎侧或新娘侧，再点“揭晓答案”。新人答案未确认的题会显示“待确认”并锁住揭晓按钮，不得临场猜答案。
6. 工具中的答对数、计时和随机历史不会写入数据库。每项游戏结束后，仍需到“团队计分”记录海岛组/沙漠组结果；家人组获胜则到“个人加分”使用家人组随机 +1 按钮。

## 如何记录团队成绩

1. 团队挑战结束后点“团队计分”。
2. 在“选择团队”中选海岛组或沙漠组，先大声复述一次队名，避免记反。
3. 用快捷按钮选择 `+1`、`+2`、`+3`、`+5` 或 `+10`；其他分数可在分数框内输入，单次范围为 1–100。
4. 在“加分原因”填写现场项目名称，例如“猜歌挑战第一名”，不要只写“加分”。
5. 点页面底部的“确认给海岛组/沙漠组加 X 分”（按钮会自动带入当前队名和分数）。看到绿色成功提示后，再核对页面当前团队总分。
6. 展开“查看最近团队计分”，确认队名、原因和数值均正确，再开始下一项游戏。
7. 团队积分结算并发放线索后，本入口会永久锁定。这是正常保护机制；团队结算前如发现误记，立即交给主控用带原因的团队积分纠正，结算后不能再修改。

## 如何记录个人加分

1. 只有主持人口头明确宣布个人奖励时才点“个人加分”；家人组赢得现场游戏时使用专用的“随机抽取一位 · +1 分”按钮。秘密任务、终局投票和系统能力分由系统自动结算，不要重复补分。
2. 在搜索框输入中文名或英文名，从结果中点击正确宾客。
3. 核对选中卡片里的头像、姓名、组别和当前积分，确认不是同名或相邻宾客。
4. 选择或输入奖励分数，在“加分原因”写清奖项，例如“现场抢答第一名”。
5. 点页面底部的“确认给某宾客加 X 分”（按钮会自动带入当前姓名和分数）。看到绿色成功提示后，展开“查看最近个人加分”再核对一次。
6. 如果选错人或分数，停止继续操作并通知主控按积分流水纠正，不要自行用负分抵消。
7. 身份结果公布后，本入口和主控纠分入口都会冻结；任何现场奖励都必须在最终公布前记录并核对。

## 如何切换婚礼环节

1. 点“流程控制”。页面会显示七张环节卡，深色卡是当前环节，描边卡是刚刚选择、尚未执行的环节。
2. 点击要进入的下一环节，例如“等待仪式”或“婚宴开始”。不要跨越正常顺序跳选。
3. 页面出现“请确认流程切换”卡片后，先读环节名称和影响说明。
4. 确认无误后点“确认切换”；若点错，点“取消”。
5. 等待绿色成功提示，并确认顶部当前环节和深色卡同时更新。
6. 再让一位现场协助者刷新宾客页，确认宾客端标题、任务开放状态和主持人台一致，之后再口播。
7. 红色错误提示会明确列出未满足条件。保留当前阶段、停止重复点击，把提示完整交给主控补齐后再试。

## 终局四个按钮的固定顺序

终局不是流程卡片。进入“婚宴互动”并完成所有团队挑战后，只能按下面顺序操作：

1. “结算团队积分并发放线索” → 核对两队分数 → 点“确认执行”。
2. 给宾客留出阅读线索的时间，再点“开启新一轮投票” → 点“确认执行”。
3. 等应投宾客全部提交后，点“关闭本轮投票” → 核对提交人数 → 点“确认执行”。
4. 与主控确认奖项已准备，再点“公布身份并结算” → 核对票数 → 点“确认执行”。

前一个步骤没有完成时，后一个按钮会变灰。不要通过切换其他婚礼环节绕过限制。

## 按钮变灰时先检查什么

- “结算团队积分并发放线索”不可用：当前必须是“婚宴互动”；20 位竞技玩家应完成抽卡；海岛组和沙漠组各有一名恶作剧者；两队已记录最终团队分；并按页面显示为正分第一名准备 2 条、其余队伍准备 1 条启用线索。
- “开启新一轮投票”不可用：团队积分和线索还没有成功结算，或当前不是“婚宴互动”。
- “关闭本轮投票”未出现：投票尚未开启。
- “公布身份并结算”未出现：至少需要创建过一轮投票；正式流程中应先关闭投票再公布。
- 加分按钮不可用：页面离线、正在提交、团队分已经结算，或终局结果已经公布。
- 任何红色错误：不要快速重复点击；错误通常是后端保护条件，不是按钮失灵。

## 婚礼开始前 60 分钟

1. 打开主持人台，确认页面显示在线、最近同步正常、当前为“宾客签到”。
2. 在全员总览确认名单可读取，海岛组和沙漠组均存在，恶作剧者身份只在私密页面可见。
3. 与主控核对注册已开放、最终投票关闭、身份结果隐藏。
4. 准备备用网络；主持人台不要使用会自动清理网页数据的无痕模式。
5. 与任务站确认审核负责人已登录，并约定“仪式开始前五分钟停止催任务”。
6. 和主控约定一个现场手势：主持人准备切换阶段时，主控先确认宾客和任务状态，再示意可以继续。

完成标志：主持人、主控和任务站三个页面都能正常刷新，主持人台显示的当前环节与主控一致。

## 完整流程总览

1. 宾客签到 - 第一轮任务领取
2. 等待仪式 - 第一轮任务进行中
3. 婚礼仪式 - 第一轮任务暂停
4. 仪式结束 - 第一轮任务恢复
5. 婚宴前奏 - 第二轮任务发放
6. 婚宴开始 - 第二轮任务进行中
7. 婚宴互动 - 团队挑战
8. 最终投票 - 恶作剧者指认
9. 身份揭晓与颁奖 - 最终积分结算

前七个环节通过“流程控制”切换；最终投票和身份揭晓必须使用专用按钮，不能从流程卡片直接跳转。

## 环节一：宾客签到

### 主持人口播

“欢迎来到婚礼现场。请扫描现场二维码，完成签到、自拍和抽卡。你的身份与任务只供自己查看，请不要把页面展示给别人。”

### 主持人操作

1. 保持流程在“宾客签到”。
2. 在全员总览观察已认领、已自拍和已抽卡进度。
3. 遇到找不到姓名、忘记密码或选错身份时，交给主控处理，不在主持台尝试修复。
4. 提醒宾客抽卡后点击隐藏身份，再进入主页。

### 宾客手机应显示

- 输入共享邀请码后选择本人姓名；
- 首次登录设置四位密码并完成婚礼自拍；
- 抽卡后看到组别、身份和第一轮任务；
- 玩家编号为随机四位字符，不按名单顺序生成。

### 完成检查

- 即将参与第一轮的宾客均已抽卡；
- 固定仪式角色已找到本人并理解任务；
- 没有人把身份页面长期展示在桌面上。

## 环节二：等待仪式

### 主持人口播

“婚礼即将开始。第一轮秘密任务已经开放，请在不影响入座和交流的情况下完成，也请保管好自己的身份。”

### 主持人操作

1. 在流程控制选择“等待仪式”，阅读确认卡后点击确认。
2. 观察任务提交数量，但不要公开谁完成了什么任务。
3. 第一轮前 3 位通过任务的宾客会各获得额外 1 点个人积分；主持人不需要手工补分。
4. 爱心、星星和恶作剧者配对均通过任务中的编号功能完成；主持人只在宾客卡住时提醒其打开“宾客列表”查询编号。

### 完成检查

- 任务站能收到待审核任务；
- 宾客任务页显示当前任务可以提交；
- 需要配对的人能看到自己的左半或右半图案。

## 环节三：婚礼仪式

### 主持人口播

“仪式即将开始，请大家收起手机，专心见证婚礼。秘密任务和伙伴确认会暂时暂停，仪式结束后自动恢复。”

### 主持人操作

1. 在流程控制切换到“婚礼仪式”。
2. 确认宾客手机出现“第一轮任务暂停”的提示。
3. 仪式进行中不要让宾客提交照片、确认配对或追问任务站。
4. 保持页面打开；不要提前切换到仪式结束。

### 完成检查

- 宾客任务仍可阅读，但提交按钮不可用；
- 页面明确说明仪式后恢复；
- 主控与任务站都显示当前为婚礼仪式。

## 环节四：仪式结束

### 主持人口播

“仪式已经结束，第一轮任务与伙伴确认现在恢复。第二轮任务还没有发放，请先完成手上的行动。”

### 主持人操作

1. 在流程控制切换到“仪式结束”。
2. 确认宾客第一轮提交和配对按钮恢复。
3. 给爱心、星星和恶作剧者配对留出最后处理时间。
4. 等主控确认第二轮前置条件全部满足后，再进入婚宴前奏。

### 重要区别

“仪式结束”只恢复第一轮任务，不会发放第二轮任务。不要为了发卡连续点击，也不要直接跳到婚宴开始。

## 环节五：婚宴前奏

### 主持人口播

“丘比特的晚宴考验已经开启。请独自打开手机，查看刚刚获得的第二轮命运；现在可以按现场节奏开始，婚宴开始后仍可继续。”

### 主持人操作

1. 等主控确认 20 位竞技玩家、两队恶作剧者、爱心和星星配对及特殊角色来源均正确。
2. 在流程控制选择“婚宴前奏”，阅读确认卡后执行。
3. 系统会一次性派发第二轮任务或能力；这一步不会部分成功。
4. 观察宾客是否出现“新的命运”弹窗，并给大家一分钟独自阅读。
5. 丘比特幸运星会在此时结算第一轮积分翻倍；主持人不要再手工加一次。

### 切换失败时

保持当前环节不变，把页面红色错误提示完整交给主控。缺少抽卡、配对或角色配置时，由主控按提示修复后再重试。不要连续点击确认，也不要跳过婚宴前奏。

## 环节六：婚宴开始

### 主持人口播

“婚宴正式开始。请享用晚宴，也可以在不打扰他人用餐的情况下继续第二轮任务。页面里可以查看今日菜单。”

### 主持人操作

1. 切换到“婚宴开始”。
2. 确认第二轮任务仍在，但不会再次派发。
3. 根据现场节奏提醒宾客查看菜单、能力说明和已解锁线索。
4. 对秘密选择任务只说明“请独立决定并提交”，不要提示哪种策略更好。

### 完成检查

- 宾客能看到第二轮任务和晚宴菜单；
- 领航星、孤单丘比特等特殊能力有来源解释；
- 恶作剧者只有展开真实界面后才看到真正任务和额外投票能力。

## 环节七：婚宴互动与团队挑战

### 主持人口播

“现在进入团队挑战。请以主持人口令为准，团队成绩会实时记录；个人秘密任务仍需保密。”

### 主持人操作

1. 切换到“婚宴互动”。
2. 在“主持游戏”按现场项目选择题库、计时器或随机数工具。使用工具不会自动计分。
3. 每轮团队游戏结束后，在“团队计分”选择海岛组或沙漠组，填写分数和明确原因再提交；即使最终为 0 分也要明确记录。
4. 如宣布个人奖励，使用“个人加分”，先搜索并核对头像和姓名。
5. 每次提交后确认成功提示和最新分数，不要因页面延迟重复点击。
6. 团队挑战全部结束后，与主控逐项核对两队最终分数。

### 分数边界

- 个人任务分只进入个人排名，不自动加入团队挑战分；
- 家人组不参加团队排名，但家人获得的个人积分会进入最终个人排名；
- 恶作剧者没有独立恶作剧积分；
- 投票和身份揭晓不能改变已经冻结的团队挑战分。

## 团队结算与线索发放

1. 确认当前仍是“婚宴互动”。
2. 确认海岛组和沙漠组都已经记录最终团队成绩。
3. 确认主控已按页面提示准备团队线索：正分第一名 2 条，其余队伍 1 条。
4. 在流程控制点击“结算团队积分并发放线索”。
5. 阅读确认卡中的两队分数后执行。
6. 正分第一名每位竞技玩家收到 2 条本队线索，其余队伍收到 1 条；正分并列第一时两队各 2 条，0:0 时两队各 1 条。恶作剧者也会收到本队线索。
7. 结算成功后团队分被锁定，后续不能继续加分。

完成标志：页面显示“团队积分已结算，线索已发放”，宾客任务页出现相应线索。

## 环节八：最终投票

### 主持人口播

“请根据整场婚礼中的观察，独立选出本队最可疑的恶作剧者。不要商量，每人只能提交一次。”

### 主持人操作

1. 确认团队线索已经发放并留出阅读时间。
2. 点击“开启新一轮投票”；系统会关闭注册并创建新的投票轮次。
3. 观察已提交人数，不公开候选人实时票数。
4. 恶作剧者若已完成真正任务，仍只选择一名玩家，但系统会把该选择按 2 票保存。
5. 确认需要参与的宾客都已提交后，点击“关闭本轮投票”。
6. 关闭后不要口头猜测结果，先与主控核对奖项和揭晓准备。

完成标志：投票状态显示已关闭，已提交人数符合现场实际。

## 环节九：身份揭晓、积分与颁奖

### 主持人口播

“投票已经封存。现在揭晓丘比特的恶作剧者、他们是否成功逃脱，以及今晚的最终荣誉。”

### 主持人操作

1. 确认本轮投票已经关闭，奖项对象和颁奖词已由主控保存。
2. 点击“公布身份并结算个人奖励”，核对确认卡中的投票人数后执行；团队挑战分保持锁定。
3. 页面会显示两名恶作剧者、是否逃脱、每位候选人获票数及实名投票来源。
4. 系统逐队判断是否抓住本队恶作剧者：恶作剧者获得本队最高加权票数（并列最高也算）即为抓住。抓住后，投中的已投票玩家获得 2 点个人积分，其他已投票玩家获得 1 点；若恶作剧者逃脱，该队所有人都不获得投票分，未投票玩家始终不加分。
5. 查看完整个人积分排名；未被抓出的恶作剧者会按荣誉规则置顶，但不会伪造额外分数。
6. 带领宾客查看公开结果和已发布奖项，再按现场顺序颁奖。
7. 终局公布不可撤回，也不能再开新投票、切回常规环节、补分或改奖项；如不再需要投屏，只让主控关闭公开大屏。

### 揭晓后核对

- 团队排名只显示海岛组与沙漠组，不显示家人组；
- 家人仍出现在个人积分榜；
- 投票来源中，额外票会标明为 2 票；
- 刷新页面不会重复结算积分。

## 婚礼结束后的收场

1. 与主控确认公开结果、奖项和最终排名已经显示正确。
2. 主控导出最终数据并关闭注册、投票和公开大屏。
3. 主持人台点击“安全退出”，确认回到工作人员登录页。
4. 不要在婚礼结束后自行执行彩排清场；正式数据应保留给主办方备份。

## 现场异常处理

- **页面离线**：页面会保留当前标签页最近一次同步的只读状态，所有加分和流程操作会禁用。切换备用网络后点击“重新连接”，不要关闭标签页。
- **流程切换失败**：保留红色错误提示，交给主控补齐条件；不要跳阶段或连续确认。
- **分数填错**：立即通知主控根据积分流水做有原因的纠正，不要用无说明的反向加分抵消。
- **任务审核堆积**：通知任务站处理，主持人不在主持台代审。
- **投票人数不足**：确认宾客页面已经刷新到投票入口，继续口头提醒；不要提前揭晓。
- **大面积断网**：暂停新抽卡、提交、记分和投票，改用纸质记录；恢复后由主控按时间顺序补录。
- **共享设备离场**：点击“安全退出”，不要只锁屏或关闭浏览器。
