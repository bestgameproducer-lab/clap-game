# 人工验收清单

每项用真实手机完成；涉及秘密身份时由两名测试者互相观察是否会泄露。

自动化视觉复核：运行 `npm run test:e2e:review` 会使用隔离测试数据生成 `artifacts/wedding-review-pack/`。手机优先打开其中的 `wedding-review-mobile.pdf`；`index.html` 使用轻量缩略图并可点击查看高清原图。两者均按婚礼时间线覆盖宾客端、主控端、主持人端、任务站和公开终局；该流程不会连接或修改生产 Supabase。Pull Request 的 Browser rehearsal 也会上传同名截图包，保留 30 天。

## 宾客入口

- [ ] 邀请码错误时看不到宾客名单。
- [ ] 中文、拼音和英文名均可搜索到目标宾客。
- [ ] 首次认领要求设置并确认四位数字密码，错误格式有清晰提示。
- [ ] 已认领宾客必须用原密码登录，其他宾客无法通过姓名进入。
- [ ] 同一宾客在另一台手机上可用姓名和原密码登录。
- [ ] 抽卡只发生一次；刷新和重复点击不会更换组别、身份或首轮任务。
- [ ] 关闭宾客注册后，尚未抽卡的身份不能再分配组别、角色或任务，并显示联系工作人员；已抽卡宾客刷新时仍能安全返回原卡。
- [ ] 关闭注册后，未设置密码的姓名不再出现在名单中且不能首次认领；已经设置密码的宾客仍可用原密码重新登录、投票和查看揭晓。
- [ ] 抽卡页在 320–430px 宽手机上无文字重叠、横向滚动或按钮遮挡。
- [ ] 切到其他应用再回来时，秘密卡自动盖住。

- [ ] 謝菲菲和孙露仪的超级幸运星在第二幕解锁时立即各发放“第一阶段积分快照 + 2”的奖励并完成；謝菲菲使用主能力卡，孙露仪使用附加能力卡，重复开启不重复加分。
- [ ] 恶作剧者可与任意数量宾客自然交流，但最多提交 5 次软件验证；普通宾客不会从 API、任务页或大屏看到验证对象、暗号结果或同伴关系。
- [ ] 联盟左右成员只收到各自的半条线索，单一响应中不包含另一片段或完整线索。
- [ ] 第一幕公开大屏不显示个人实时积分榜，但团队进度仍可展示。
- [ ] 打印宾客卡页面要求管理员会话，并且不打印基础隐藏阵营。
- [ ] 首次登录或尚未设置头像的宾客必须拍摄一张婚礼自拍；照片经客户端裁切压缩后存入私密头像桶，只有已登录宾客可在验证列表中通过短时链接看到头像、姓名和编号。
- [ ] 宾客验证列表默认展示已抽卡宾客并支持姓名搜索；不返回分组、身份、任务、登录名或凭据，查看与复制编号不消耗验证次数。

- [ ] 未到对应阶段的任务不会提前显示。
- [ ] 退出后再次登录不会把已有或已完成任务提示成“新任务”；只有同一登录会话中新出现且仍需处理的任务才弹提示。
- [ ] 宾客只可在第一轮、第二轮和团队挑战中提交当前或已经开放的任务；投票/揭晓后手机端隐藏提交与照片入口，直接调用 API 和数据库函数也会被拒绝。
- [ ] 提交后显示待审核；退回后显示原因并允许再次提交。
- [ ] 每项任务显示明确的验证方式；宾客可附带完成说明，提交后后台和任务站均能看到。
- [ ] 宾客可上传、更换或删除一张验证照片；大多数任务将照片作为可选证据，`P2-SOCIAL-003` 与 `P2-SOCIAL-004` 必须先上传照片才能提交。超过限制的照片会先在手机端压缩，弱网时可由任务站代传或按现场政策留存后补录。
- [ ] 任务站可替宾客添加、更换或删除尚未完成任务的验证照片；待核验照片同样先压缩、只存私有空间，所有工作人员确认或删除均进入审计日志。
- [ ] 验证照片不公开、不进入离线缓存；只有任务本人和已登录工作人员能通过短时链接查看。
- [ ] 后台或任务站点击“通过并加分”不依赖浏览器弹窗；审核备注留空时自动记录任务预设的核验要求，填写时保存现场备注；退回必须填写宾客可见原因。
- [ ] 通过后任务立即离开待审核列表，宾客可查看核验记录，任务 CSV 包含说明、核验人员和核验时间。
- [ ] 通过后只加分一次，重复请求不会重复加分。
- [ ] 正式任务的分值、机制和人数容量与版本化任务清单完全一致；后台只能查看正式 `P1-*`/`P2-*` 任务。主办方自建临时任务通过独立校验，不能伪装成正式任务。
- [ ] 前 3 位由工作人员核验通过首轮任务的宾客都看到对应名次荣誉提示，并各获额外 1 点个人积分。配对和能力卡等系统自动完成任务不占用这 3 个名额；首轮审核不会发放升级任务或秘密线索，团队线索只在团队挑战结算后按名次发放。
- [ ] 私人任务、角色和线索不会出现在公共接口或未揭晓的大屏。
- [ ] 旧“一次性隐藏任务实体卡/隐藏第三名恶作剧者”已退役：后台、任务站、现行 API 和任务列表均无生成、展示、兑换或角色升级入口。
- [ ] 历史迁移中的代码散列、RLS 和加密测试继续保留用于兼容审计，但旧数据不能重新进入当前正式任务、宾客任务或线索发放流程。

## 后台与终局

- [ ] 使用 32 位正式宾客、32 个登录账号时，后台预检能验证家人组 10 个账号、海岛组和沙漠组各 10 人，以及每个竞技组最多 1 名丘比特恶作剧者、9 名婚礼守护者；任何预设超额都会阻止显示“可以开场”。
- [ ] 后台必须把公开示例邀请码更换为正式码后才能显示“可以开场”；数据库、后台读取接口和审计日志均不返回邀请码原文。
- [ ] 开场预检只包含 6 项核心条件：流程状态、正式邀请码、32 位宾客/32 个登录账号三组名单、竞技组抽卡容量、第一轮正式任务和固定职务。团队线索不阻塞开场，而是在团队结算入口单独校验。
- [ ] 彩排清场会先关闭注册、投票和大屏，并要求八类清场前核对记录确认、3–300 字原因、固定确认词和页面内最终确认；核对记录包含线索库和线索发放记录，但明确不是完整恢复包，不包含照片二进制、密码与会话或密封选择。
- [ ] 重复提交同一个清场事件不会重复写入审计；清场保留正式配置、管理员会话和审计，但删除全部宾客运行数据、已发线索和整个线索库；任何旧实体卡领取状态只作为遗留兼容数据清理，不会恢复成可用玩法。
- [ ] 清场把未锁定的随机队伍/身份恢复为未分组/普通宾客并保留后台锁定的初始预设；遗留的隐藏第三名恶作剧者标记会清除，当前抽卡仍只产生每队一名正式恶作剧者。
- [ ] 清场后的验证照片和宾客自拍从私有存储删除，包括上传成功但数据库确认失败的孤立对象；若存储临时失败，待删除路径只保存在受保护记录中，并能在刷新或重新登录后使用同一事件安全重试。
- [ ] 只要任一清场记录仍有待删验证照片或自拍路径，数据库就拒绝重新开放注册和开始另一场清场；清理完成后才允许新宾客自拍，旧重试不能删除新一轮照片。

- [ ] 错误管理员密码无法登录；未登录不能读取后台数据或 CSV。
- [ ] 同一设备连续输错五次管理员密码后收到 429 和明确等待时间，十五分钟内即使继续尝试也不会创建工作人员会话；数据库只保留不可逆指纹。
- [ ] 后台、主持台和任务站均可安全退出；退出后原管理员 Cookie 立即失效，不能继续读取任何工作人员数据。
- [ ] 后台可新增宾客并修改显示姓名、登录名、桌号、长辈标记、仪式任务标记和工作人员备注；导出的宾客 CSV 包含这些运营字段。
- [ ] 关闭注册后可从三列表格或分隔文本批量预览并新增 1–100 位宾客；重复、已存在或格式错误的登录名会让整批回滚，注册开放时前端、API 和数据库均拒绝导入。
- [ ] 已设置密码的宾客不能直接更换登录名；停用未抽卡宾客会立即撤销其全部会话，并从认领名单和任务站消失。
- [ ] 已经抽卡的宾客不能被停用，避免其任务、组别完成率和积分历史失去归属。
- [ ] 重置密码后，宾客现有会话失效且可以重新设置密码。
- [ ] 终局公布前，开启新投票会创建新轮次并隔离旧票；公布结果会关闭投票。终局公布后不能开启新轮次或隐藏揭晓。
- [ ] 每位宾客每轮只能投一次，提交后立即锁定；重新开放会创建新轮次且不会混入旧票。
- [ ] 公布结果时，猜中恶作剧者的宾客自动获得 2 分；该奖励每人每轮只发一次，双重裁决只增加票权、不重复个人奖励；团队积分在投票前结算后保持冻结。
- [ ] 公开团队榜只汇总团队积分流水；个人任务分无论多高都不能改变团队排名，但仍正常显示在个人荣誉榜。
- [ ] 旧版高分任务的历史校准流水不会被删除或重写；当前正式分值只以版本化任务清单为准。
- [ ] 环节下拉框不能直接选择“最终投票”或“身份揭晓”；API 与数据库同样拒绝绕过专用按钮，避免产生没有轮次或没有结算的终局状态。
- [ ] 后台可发布或清空最多 500 字的宾客端环节提示；宾客手机自动同步，公开大屏不显示这条内部行动提示，操作进入审计。
- [ ] 开启新投票前必须完成一次显式团队线索结算；结算要求 20 位竞技玩家完成抽卡、每队恰好 1 名恶作剧者、两队已记录团队成绩，且线索库已满足当前成绩所需数量（正分第一名 2 条，其余队伍 1 条）。开启后系统自动关闭注册、创建新轮次并清空上一题、公开线索和倒计时。
- [ ] 首次“公布并结算”是不可逆终局：不能隐藏揭晓、切回常规环节、重新开放注册或开启新投票；如只需停止公开展示，可单独关闭大屏。
- [ ] 重复点击或重试“公布并结算”不会重复发放任何终局奖励，并返回清晰的“本场已冻结”状态。
- [ ] 终局公布后，任务通过/退回、个人或团队积分、线索新增/停用/补发、奖项和任务配置在 UI、API 与数据库三层全部拒绝；读取和导出仍可使用。
- [ ] 恶作剧者保留身份、伪装任务、同伴确认和最终揭晓，但不存在独立恶作剧积分或补记入口；其普通任务分和主持人游戏个人分只是伪装分，不占第一轮前三荣誉，揭晓后不参与名次且不显示。
- [ ] 公布结果不会因恶作剧者逃脱投票、所在队伍第一或完成恶作剧任务而额外写入个人或团队积分；已完成第二轮真实任务的恶作剧者只获得双票能力，并在真实界面收到明确提示。

- [ ] 家人组不显示在最终团队榜，但可通过现场互动获得个人积分并显示在完整个人榜；主持人在团队挑战阶段每次点击家人组专用胜利按钮时，服务器随机选择一名可计分家人并只增加 1 点个人分，重复请求不会重复记账；投票前冻结的海岛组、沙漠组团队分在身份揭晓后保持完全一致。
- [ ] 主控、主持人和公开大屏的终局只揭晓两位恶作剧者及其“成功逃脱/已被识破”结果，不逐人列出普通守护者；逃脱恶作剧者置顶、被抓恶作剧者置底且均不显示积分，其余排名包含家人并按个人总分排列。
- [ ] 孤单丘比特只能锁定另一位第二阶段竞技玩家；最终揭晓时事务性地给目标 -3 分、本人 +3 分，目标允许降至负分，重复结算不会再次转移。
- [ ] 大屏开关独立生效，未开放时不显示排名数据。
- [ ] 结果未公布时，大屏不显示秘密身份或个人投票。
- [ ] 旧竞拍金币账本不出现在当前主持流程、后台导出或计分中；历史表仅用于数据库兼容与安全清场。
- [ ] 八种核对 CSV（宾客、任务、个人积分、团队积分、线索库、线索发放、奖项、审计）均能下载并用 Excel 打开，且不包含密码哈希、会话或服务密钥；产品和文档不把它们承诺为可恢复照片、密码/会话或秘密选择的完整备份。

- [ ] `/host` 显示当前阶段、本轮投票完成数，并可按顺序切换常规婚礼流程、结算团队线索、开启/关闭投票和公布结果；身份未揭晓前不显示公开排名结果。

- [ ] 未选择获奖宾客或组别时不能发布奖项；未公开总结果时公开大屏不显示奖项；终局公布后奖项内容和发布状态均冻结。

## 弱网和恢复

- [ ] 登录后断网，页面显示离线提示和最近缓存，不显示白屏。
- [ ] 主持人流程台成功同步一次后，断网仍能查看当前标签页最近的私密全员总览、流程与积分；流程切换、团队/个人计分和终局操作全部禁用，恢复联网后自动同步，也可手动重连。
- [ ] 主持人私密离线副本只存在于当前标签页的 `sessionStorage`；安全退出或工作人员会话返回 401 后被清除，`localStorage` 和 Service Worker 中均不存在主持人私密数据。
- [ ] 任务站成功同步一次后，断网仍能搜索并查看当前标签页最近的宾客和任务文字；核验、退回、派发自定义任务、补发线索和积分补记全部禁用，恢复联网后自动同步，也可手动重连。
- [ ] 任务站私密离线副本只存在于当前标签页的 `sessionStorage`；安全退出或工作人员会话返回 401 后被清除，验证照片与 `/api/` 响应均不进入 Service Worker 缓存。
- [ ] 大屏成功联网一次后，当前投影标签页断网或刷新仍可打开页面壳和最近公开结果；页面显示 `CACHED`、最近同步时间和重连按钮，不会把 API 响应或揭晓结果写入长期 `localStorage`。
- [ ] 联网打开一次宾客任务页并看到“弱网备用已准备”后，切断网络再刷新，页面壳和本次会话最近任务仍可打开。
- [ ] Service Worker 缓存中没有 `/api/` 响应，也无法离线打开 `/admin`、`/host` 或 `/station`。
- [ ] 断网时点击“退出此身份”会明确提示需要联网，不会假装退出；恢复网络后退出会撤销服务器会话并清除本机任务缓存。
