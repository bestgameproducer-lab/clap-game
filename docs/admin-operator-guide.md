# 主办方后台使用指南

访问入口：`/admin`

## 主控职责与安全原则

主控后台是婚礼游戏的最高权限操作台，负责开场检查、宾客管理、任务审核、流程控制、内容配置、终局结算、备份和安全清场。所有修改都会写入审计记录。

管理员密码不能投屏、发群或交给宾客。不要在婚礼当天修改数据库、运行 seed、覆盖名单或清空生产数据。彩排清场只允许在完成七类 CSV 备份、确认当前不是正式活动后执行。

## 顶部四个主入口

1. **开场与宾客**：系统状态、开场检查、注册进度、自拍与抽卡进度、宾客资料和密码重置。
2. **现场执行**：流程控制、任务审核、临时提示、大屏内容和团队挑战计分。
3. **终局结算**：确认奖项、结算团队积分并发放线索、开启/关闭投票、公布身份与积分、核对奖项和积分流水。
4. **婚礼设置**：任务与线索内容、角色预设、奖项配置、管理员密码、数据导出与彩排清场。

占空间较大的配置区默认折叠；只有需要操作时再展开，完成后收起，避免在手机上误触其他模块。

## 开场前检查

1. 打开“开场与宾客”，确认系统在线、部署版本和最近同步时间正常。
2. 展开“开场检查”，处理所有红色或橙色项目。重点核对 32 人名单、家人组/海岛组/沙漠组人数、第一轮任务容量、固定仪式角色和随机恶作剧者池。
3. 在“宾客注册与游戏进度”确认已认领、已上传头像、已抽卡和未注册人数。点击宾客明细可按姓名搜索、查看头像和重置密码。
4. 确认正式邀请码已设置，但不要在后台截图中暴露邀请码。
5. 注册开放前，用备用手机走一次邀请码、姓名搜索、四位密码、自拍和抽卡。

## 现场执行

### 流程控制

按婚礼时间线依次切换：宾客签到、等待仪式、婚礼仪式、仪式结束、婚宴前奏、婚宴开始、婚宴互动。每次切换都必须看清确认卡中的影响范围。

- “仪式结束”恢复第一轮提交，不派发第二轮任务。
- “婚宴前奏”校验配对和特殊角色，并一次性派发第二轮任务。
- “婚宴开始”只开放第二轮行动，不重复派发任务。
- “婚宴互动”开放团队挑战，并允许之后进入团队结算和投票。

临时补充提示只填写所有宾客都可以看到的内容，结束后及时清空。大屏内容同样不能写入正确答案、隐藏身份或秘密任务。

### 任务审核

1. 打开“现场执行 - 任务审核”。
2. 核对宾客姓名、任务标题、核验要求、完成说明和验证照片。
3. 符合要求时点击“通过并加分”；系统会按任务预设分值记入个人积分流水。
4. 不符合时填写宾客可见的明确原因，再点击“退回”。
5. 前 3 位完成首轮任务的宾客各获得额外 1 分；页面只提示积分奖励，不会显示升级任务或秘密线索奖励。

不要为了让数字看起来正确而重复点击。成功后任务会立即离开待审核队列；如果页面报错，应保留错误信息并先检查网络。

## 终局结算顺序

1. **确认颁奖结果**：提前填写奖项名称、获奖人或队伍和颁奖词；只有勾选“随身份揭晓公布”的奖项才会出现在公开结果。
2. **结算团队积分并发放线索**：确认 20 位竞技玩家已抽卡、每队恰好 1 名恶作剧者、已记录团队分、每队至少 2 条启用线索。
3. **开启并收集最终投票**：开启新轮次会关闭注册并清空上一轮投票。身份揭晓前后台只用于观察提交人数。
4. **关闭投票**：确认现场所有需要参与的宾客已经提交。
5. **公布身份并结算全部积分**：系统会公开恶作剧者、逃脱结果、实名投票来源和完整个人排名。重复刷新不会重复加分。
6. **核对奖项与积分流水**：确认最终排名和主持人口头颁奖一致，再开放或投屏公开结果。

团队积分在第 2 步会生成冻结快照，后续个人任务、投票奖励和身份揭晓不会再改变团队挑战结果。家人组不参加团队排名，但家人通过现场互动获得的个人积分会进入个人排名。

## 婚礼设置与数据

- **任务与角色**：只修改确认过的正式内容；已经抽卡后不要停用相关任务或改变角色容量。
- **团队线索库**：现场新建线索时必须指定海岛组或沙漠组。不要保留空白或默认占位线索。
- **奖项**：先保存获奖对象和颁奖词，再决定是否随结果公布。
- **管理员密码**：更换会让主控、主持人和任务站全部退出；婚礼进行中不要更换，除非确认发生泄露。
- **数据导出**：彩排结束后和婚礼结束后各导出一次宾客、任务、个人积分、团队积分、竞拍金币、奖项和审计记录。
- **彩排安全清场**：不可从网页撤销。必须先备份、填写原因并完成两次确认；正式婚礼开始后不要使用。

## 故障恢复

- **页面没有更新**：先确认网络和“最近同步”，再刷新一次；不要连续重复提交。
- **宾客忘记密码**：核对本人后，在宾客明细中重置；该宾客所有旧会话会退出。
- **任务审核失败**：阅读错误提示，确认任务仍是“待审核”再重试；不要另外手工加一次同样分数。
- **第二轮切换失败**：按错误提示核对 20 位竞技玩家、两队恶作剧者、爱心/星星配对与特殊角色来源；修正后再次确认切换。
- **团队结算按钮不可用**：确认当前流程为“婚宴互动”、两队已有团队成绩并且每队至少准备 2 条启用线索。
- **大面积断网**：停止产生新抽卡和新提交，使用纸质记录；恢复后按时间顺序补录并写明“现场离线补录”。
- **操作完成**：所有工作人员页面点击“安全退出”，再关闭共享设备。
