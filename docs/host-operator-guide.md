# 主持人流程台使用指南

访问入口：`/host`

## 主持人的职责边界

主持人负责查看全员状态、切换婚礼环节、记录团队或个人现场奖励、控制最终投票并公布结果。主持人页包含恶作剧者身份，必须只在主持人自己的设备上使用，不能投屏、截图发群或交给宾客查看。

任务提交的证据核验和通过/退回由任务站处理；宾客资料、密码重置、任务与线索配置、奖项维护和数据备份由主控后台处理。

## 页面四个入口

1. **全员总览**：查看每位宾客的组别、抽卡状态、个人积分和恶作剧者身份。
2. **团队加分**：团队挑战时选择海岛组或沙漠组，填写加分数值和现场原因。团队积分结算后会锁定，不能继续修改。
3. **个人加分**：仅用于主持人现场明确宣布的个人奖励；先搜索并核对姓名，再填写分值与原因。
4. **流程控制**：切换七个婚礼环节，并依次完成团队结算、投票和身份揭晓。

## 婚礼流程顺序

必须按以下顺序推进，每次点击后都要在确认卡中再次确认：

1. 宾客签到 - 第一轮任务领取
2. 等待仪式 - 第一轮任务进行中
3. 婚礼仪式 - 第一轮任务暂停
4. 仪式结束 - 第一轮任务恢复
5. 婚宴前奏 - 第二轮任务发放
6. 婚宴开始 - 第二轮任务进行中
7. 婚宴互动 - 团队挑战

“仪式结束”只恢复第一轮任务；“婚宴前奏”才会一次性派发第二轮任务。切换失败时保留页面错误提示，按提示补齐玩家抽卡、配对或角色配置后再重试，不要连续点击。

## 团队挑战与终局

1. 在“团队加分”中录入两队最终成绩，并核对原因。
2. 进入“流程控制”，确认页面显示 20/20 名竞技玩家已抽卡、每队 1 名恶作剧者、每队至少 2 条可发放线索。
3. 点击“结算团队积分并发放线索”。结算成功后团队分数被锁定；后续投票不会改变团队分。
4. 点击“开启新一轮投票”，提醒宾客在手机上完成本队指认。
5. 根据页面提交人数确认现场进度；确认结束后点击“关闭本轮投票”。身份揭晓前不要公开实时票数。
6. 点击“公布身份并结算全部积分”。系统会揭晓恶作剧者、显示是否逃脱、列出每位候选人的实名投票来源，并完成最终个人积分排名。
7. 带领宾客查看最终排名和已发布奖项。

恶作剧者完成真正任务并解锁额外一票后，最终仍只选一个人，系统会把这一票按 2 票保存。投中本队恶作剧者的玩家获得 2 点个人积分。

## 现场异常处理

- **页面离线**：主持人台会显示当前标签页最近一次同步的只读状态，加分和流程操作会自动禁用。切换备用网络后点击“重新连接”，不要关闭标签页。
- **切换失败**：阅读红色错误提示，补齐提示中的条件后重试；不要跳过阶段或反复点击确认。
- **分数填错**：立即联系主控后台，根据积分流水做有原因的纠正记录，不要用另一次无说明加分抵消。
- **投票人数不足**：先关闭口头催促之外的流程，确认宾客页面是否已刷新到投票入口；不要提前公布结果。
- **共享设备离场**：点击“安全退出”，确认返回工作人员登录页。

## 主持人口头提示速查

- 仪式开始：“现在请收起手机，第一轮任务暂时停止。”
- 仪式结束：“第一轮任务已经恢复，请在不打扰他人的情况下继续。”
- 婚宴前奏：“请打开页面查看刚刚获得的第二轮命运。”
- 团队挑战：“请以主持人口令为准，团队成绩会实时记录。”
- 最终投票：“请独立判断、不要商量，只能提交一次。”
- 身份揭晓：“投票已经封存，现在揭晓丘比特的恶作剧者和最终荣誉。”
